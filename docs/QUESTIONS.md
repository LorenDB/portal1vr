# Open questions

### Q-001: Download Portal: Prelude RTX (26 GB) for an offline look?
Why it matters: it is in the library but not downloaded. If its maps and content run on Portal's engine without RTX, as Rexaura's do, Prelude could be played in VR, though never with RTX (D-002). That can only be checked against the files.
Default if unanswered: Prelude stays unsupported and isn't downloaded.

### Q-002: Which game does Steam show while Rexaura VR runs?
Why it matters: Rexaura's maps fire three of Portal's achievement events. If Steam shows Portal, those Portal achievements can unlock from playing Rexaura.
Default if unanswered: the README warns that they may unlock.

### Q-003: Which graphics card is in this PC?
Why it matters: only for any future RTX work (D-002); nothing current depends on it.
Default if unanswered: not needed.
